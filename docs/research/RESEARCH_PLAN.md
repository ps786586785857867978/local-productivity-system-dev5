## Questions for every product

1. What is the product's primary purpose and intended user?
2. Which features are essential to its core workflow?
3. Which features are useful but not essential for this assignment?
4. Which features add unnecessary complexity for a local student-focused application?
5. How does the product handle task capture, planning, focus, history, and feedback?
6. What interaction or visual ideas are worth adapting without copying?
7. What recurring user problems suggest opportunities for a custom feature?

## Required synthesis

- Essential features
- Useful features
- Unnecessary features
- One or two original product ideas
- Findings that should become Grill questions
- Source list with inline citations
