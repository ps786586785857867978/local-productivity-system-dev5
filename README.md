# Dev 5 — Local Productivity System

A combined offline desktop productivity application containing task management and Pomodoro/time tracking, with local persistence and append-only Markdown logging to a user-selected Obsidian vault.

## Status

Project setup and research tracking are in progress.

## Assignment workflow

1. Research three task-management products and three Pomodoro/time-tracking products.
2. Run a Grill session and produce a testable PRD.
3. Create at least three visual design references.
4. Build and test the application.
5. Generate real Obsidian records through the finished application.
6. Produce the final report, clean-clone verification, and submission files.

## Tracking

- Project decisions and research are committed to this repository.
- A parallel project journal is maintained in the user's Obsidian vault.
- Application-generated vault samples will be kept separate from planning notes.
